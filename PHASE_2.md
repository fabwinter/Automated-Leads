# Phase 2: Outreach Queue — User Guide

## What's New

Phase 2 adds **outreach queue management**. For each qualified lead with a demo, the engine:

1. Drafts personalized emails using Claude (based on business issues + demo URL)
2. Stores drafts in an approval queue (manual review before sending)
3. Allows editing, approving, and sending emails one-at-a-time
4. Sends emails via Resend (compliant with Spam Act 2003 — no auto-send)
5. Tracks delivery and reply status

## Architecture

```
Qualified Lead + Demo (Phase 1)
        ↓
   [Draft Outreach button]
        ↓
Worker: /draft
  ├─ Fetch lead + audit + demo
  ├─ Call Claude: business data + issues → email subject + body
  └─ Store in outreach table (status=draft)
        ↓
Dashboard: Outreach Queue
  ├─ Show draft email
  ├─ Allow edit, approve, send (manual workflow)
  └─ Track status: draft → approved → sent
        ↓
API: /send-email
  └─ Call Resend API → send email
```

## How to Use

### 1. Generate Demos for Qualified Leads

From the **Worklist** page:

1. Click "Generate Demo" on any qualified lead
2. Wait ~10–15 seconds for demo generation
3. Lead status changes to `demo_ready`

### 2. Draft Outreach Emails

**From Worklist:**
- Once demo is ready, click "Draft Email" button on the lead row
- Or click the "Outreach Queue (N)" link in the top-right

**From Outreach Queue page:**

1. Go to `/runs/[runId]/outreach`
2. See table of all draft-ready leads
3. For each lead:
   - Click "Draft" button → Claude generates subject + body
   - Review generated email
   - Click "Edit" to customize (e.g., fix personalization, add custom touch)
   - Click "Approve" once satisfied
   - Click "Send" to deliver via Resend

### 3. Email Workflow

**Status transitions:**
- `draft`: Email generated by Claude, awaiting review
- `approved`: Manually approved, ready to send
- `sent`: Delivered via Resend
- `bounced`: Email address invalid or rejected by ISP
- `replied`: Customer responded (requires manual tracking)

**Timeline:**
1. Draft email takes ~3–5 seconds (Claude call)
2. Edit as needed (manual)
3. Approve (1 click)
4. Send (1 click) → email delivered in real-time

### 4. Optional: Follow-up Auto-Draft

For Phase 2+:
- Manual creation of follow-up email at +3 days
- Scheduled for implementation in Phase 3

## Email Content

Claude generates two fields:

**Subject:** ~50–60 characters
```
"See your new website design"
"Quick redesign preview for [Business]"
```

**Body:** ~150–200 words
```
Hi [Name],

I came across [Business] and noticed [issue].

I designed a quick concept for your site to show what's possible:
https://[demo-url].demos.example.com

Take a look and let me know what you think!

Best,
[Sender]
```

**Rules Claude follows:**
- Opens with personalization (business name, issue, or recent review)
- Clearly references ONE issue from audit (no generic pitch)
- Links demo as primary CTA
- Professional but conversational tone
- No adjectives like "amazing", "awesome", "incredible"
- Signature is light (no formal closing)

## API Reference

### POST `/draft` (Worker)

Generate draft email for a lead.

```bash
curl -X POST http://localhost:8787/draft \
  -H "Content-Type: application/json" \
  -d '{
    "lead_id": "uuid",
    "run_id": "uuid"
  }'
```

**Response (201):**
```json
{
  "status": "success",
  "outreach_id": "uuid",
  "draft_subject": "...",
  "draft_body": "..."
}
```

### GET `/api/outreach?lead_id=uuid` (Dashboard)

Fetch outreach record for a lead.

**Response:**
```json
{
  "id": "uuid",
  "lead_id": "uuid",
  "channel": "email",
  "subject": "...",
  "body": "...",
  "status": "draft|approved|sent|replied|bounced",
  "sent_at": "2024-01-15T10:30:00Z",
  "created_at": "2024-01-15T10:25:00Z"
}
```

### PUT `/api/outreach` (Dashboard)

Update draft (edit, approve, or change status).

```json
{
  "lead_id": "uuid",
  "subject": "New subject",
  "body": "New body",
  "status": "approved"
}
```

### POST `/api/send-email` (Dashboard)

Send approved email via Resend.

```json
{
  "lead_id": "uuid",
  "to": "owner@business.com",
  "subject": "...",
  "body": "..."
}
```

**Response (200):**
```json
{
  "status": "success",
  "messageId": "resend-message-id"
}
```

## Configuration

**Required env vars:**
- `RESEND_API_KEY`: API key from Resend dashboard
- `RESEND_FROM_EMAIL`: Verified sender email (e.g., `noreply@yourdomain.com`)

**To set up Resend:**

1. Go to https://resend.com
2. Create account
3. Add verified sender domain
4. Get API key from dashboard
5. Add to `.env.local`:
   ```
   RESEND_API_KEY=re_123abc...
   RESEND_FROM_EMAIL=noreply@yourdomain.com
   ```

## Performance & Cost

### Draft Generation
- Time: ~3–5 seconds per email (Claude API call)
- Cost: ~$0.01 per draft (token-based)
- Batch: 100 leads = ~5–10 minutes + ~$1

### Email Sending
- Time: <1 second per email (Resend API)
- Cost: Free tier up to 100/day; then $0.30–$0.35 per 1,000 emails
- Tracking: Open rate, click tracking, bounce handling included

### Database
- Outreach table: ~200 bytes per record
- 1,000 leads = ~200 KB = negligible storage cost

## Guardrails

✅ **Manual sends only.** No auto-send logic. Each email requires click → approval → send.  
✅ **Verified domain.** Resend requires verified sender domain (prevents abuse).  
✅ **One-at-a-time.** Send button sends ONE email per click (complies with Spam Act 2003 AU).  
✅ **No list purchase.** All leads are verified Google Places businesses (real, opt-in-able).  
✅ **Reply tracking optional.** Can manually mark replies in dashboard (Phase 3: auto-detection via email parsing).

## Troubleshooting

### Draft generation fails

**Error: "Claude API timeout"**
- Solution: API call took >30s
- Fix: Retry (handled automatically)

**Error: "Lead not found"**
- Solution: Lead ID is wrong or lead doesn't exist
- Fix: Verify lead was audited before drafting

### Email won't send

**Error: "Invalid sender email"**
- Solution: `RESEND_FROM_EMAIL` not verified in Resend dashboard
- Fix: Go to Resend → Domains, verify email, add to .env

**Error: "Bounced"**
- Solution: Email address invalid or ISP rejected it
- Fix: Check lead.email field in database, correct and retry

### Email looks plain text

- Issue: Email body sent as plain text without formatting
- Solution: Claude generates plain text; dashboard converts to HTML
- Note: Resend sends as HTML email (check Gmail preview)
